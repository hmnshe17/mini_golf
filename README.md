# mini_golf
Camera-guided putting platform with automatic two-axis tilt control. MEAM 5160 final project.

To start working, open a terminal in the folder where you want the project and do the following:

git clone --branch haitham_test https://github.com/hmnshe17/mini_golf.git

cd mini_golf

Now you should be able to see the repo in your folder. 
Make sure to push changes to git continuiusly.
